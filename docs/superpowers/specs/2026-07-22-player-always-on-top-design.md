# 播放器始终置顶功能设计

## 目标

为播放器窗口增加“始终置顶”能力，使用户可以在播放期间将播放器保持在其他应用窗口之上。功能默认关闭，仅在当前应用运行期间保留，不写入持久化配置。

## 已确认需求

- 仅播放器窗口支持始终置顶，主窗口和其他对话框不受影响。
- 标题栏提供可勾选的图钉按钮。
- 视频右键菜单同时提供可勾选的“始终置顶”菜单项。
- 两个入口共享同一状态并即时同步。
- 不新增键盘快捷键，也不修改 F1 快捷键帮助。
- 播放器返回主窗口后会隐藏并复用，置顶状态在本次应用运行中继续保留。
- 应用重启或创建全新的播放器实例后，置顶状态恢复为关闭。
- 不修改 `AppConfig`、设置数据库或配置迁移逻辑。

## 方案选择

采用 `PlayerWindow` 内部的 Qt 原生窗口标志实现：通过 `Qt.WindowType.WindowStaysOnTopHint` 控制置顶，并由播放器窗口本身维护瞬时状态。

未采用以下方案：

- 将置顶能力加入通用窗口基类：本次只有播放器需要，扩大基类职责没有必要。
- 调用 Windows、X11 或 Wayland 原生接口：跨平台维护成本高，也会绕过现有 Qt 窗口体系。

## 组件与职责

### PlayerWindow 状态

`PlayerWindow` 创建时将置顶状态初始化为关闭。状态只存在于该窗口实例中，不从配置加载，也不保存到配置。

播放器从主窗口打开、返回主窗口以及再次显示时会复用同一实例，因此状态自然保留。全新的 `PlayerWindow` 实例始终从关闭状态开始。

### 统一切换入口

播放器提供一个统一方法接收目标布尔状态，负责：

1. 记录切换前的可见性和窗口状态。
2. 只增删 `WindowStaysOnTopHint`，保留无边框等现有窗口标志。
3. 在 Qt 因修改窗口标志而重建原生窗口时，恢复普通、最大化或全屏显示状态。
4. 读取实际窗口标志，确定最终状态。
5. 同步标题栏按钮和右键菜单入口。

标题栏按钮和右键菜单不得分别实现窗口标志切换逻辑。

### 标题栏入口

在现有“返回主窗口”按钮旁增加一个可勾选的图钉按钮，并使用与项目现有图标风格一致的新 SVG 图标。

- 关闭时提示为“始终置顶”。
- 开启时提示为“取消始终置顶”。
- 选中状态始终反映实际窗口标志。

全屏状态下标题栏按现有行为隐藏；退出全屏后按钮重新显示，并保持正确状态。

### 视频右键菜单入口

视频右键菜单在“视频信息”和“退出播放”附近增加可勾选项“始终置顶”。菜单每次创建时从播放器当前状态初始化勾选值，触发后调用统一切换入口。

全屏时仍可通过视频右键菜单切换置顶状态。

## 状态流

```text
标题栏按钮 ─┐
             ├─> PlayerWindow 统一切换方法
右键菜单项 ─┘          │
                       ├─> Qt WindowStaysOnTopHint
                       └─> 同步按钮、菜单和提示文字
```

不经过配置对象、设置仓库或数据库。

## 窗口状态处理

Qt 在运行时修改顶级窗口标志时可能暂时隐藏或重建原生窗口。切换逻辑必须遵循以下规则：

- 原先隐藏：修改标志后仍保持隐藏。
- 原先普通显示：恢复普通显示。
- 原先最大化：恢复最大化显示。
- 原先全屏：恢复全屏显示。
- 开启置顶后可以提升窗口层级，但不得强制改变播放、侧栏或全屏状态。

返回主窗口只隐藏播放器，不重置置顶状态。

## 异常与平台差异

Qt 和桌面窗口管理器负责实际置顶行为。若平台不支持该提示或切换发生异常：

- 以实际 `windowFlags()` 中的标志为最终状态。
- 将两个入口恢复为实际状态。
- 在播放器日志中记录失败信息。
- 不弹出模态对话框，以免打断播放。

不为单个平台增加专用原生实现。

## 测试设计

使用现有 `tests/test_player_window_ui.py` 测试模式，按测试驱动流程覆盖：

1. 新建播放器默认未设置 `WindowStaysOnTopHint`，标题栏按钮未选中。
2. 标题栏按钮开启和关闭置顶时，实际窗口标志随之变化。
3. 右键菜单项反映当前状态，并能切换窗口标志和标题栏按钮。
4. 两个入口在连续交替操作后仍保持同步。
5. 隐藏并重新显示同一播放器实例后状态保留。
6. 创建新的播放器实例后状态恢复关闭。
7. 切换不会修改配置，也不会调用配置保存回调。
8. 普通、最大化和全屏窗口在切换后恢复原有状态。
9. 运行播放器窗口相关测试以及必要的完整测试集，确认没有破坏全屏、标题栏、右键菜单和窗口几何行为。

## 非目标

- 主窗口或其他窗口置顶。
- 快捷键及 F1 帮助项。
- 跨应用重启持久化。
- 设置页面中的置顶选项。
- Windows、X11 或 Wayland 专用 API。

## 验收标准

- 用户可从标题栏图钉按钮和视频右键菜单开启或关闭播放器置顶。
- 两个入口始终显示相同的实际状态。
- 置顶不影响播放器现有的普通、最大化、全屏、隐藏和恢复流程。
- 返回主窗口再打开播放器时保留状态；重启应用后默认关闭。
- 功能不产生配置数据库变更。
