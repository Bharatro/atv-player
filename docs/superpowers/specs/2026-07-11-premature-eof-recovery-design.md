# 网盘代理提前 EOF 恢复设计

## 背景

百度网盘、115 等媒体通过本地网盘代理 URL 播放时，代理或 mpv 可能在视频尚未接近片尾时发出 EOF。一次实际日志中，本集总长为 44:41（2681 秒），播放器在 16:43（1003 秒）收到结束事件并直接切换到下一集，剩余约 28 分钟。

当前 `PlayerWindow._handle_playback_finished()` 仅对最近两秒内的手动 seek 做特殊处理。其他 `playback_finished` 事件会被无条件视为正常播完并调用 `play_next()`。同时，进度定时器的片尾自动切集直接使用 mpv 当前报告的时长；如果代理流令时长暂时缩短，也可能误触发下一集。

## 目标

- 正常播放过程中收到明显提前的 EOF 时，恢复当前集而不是跳到下一集。
- 代理临时报告较短时长时，不触发片尾自动切集。
- 真正播放到片尾时继续自动播放下一集。
- 修复对播放源保持通用，不硬编码百度网盘、115 或代理 URL。
- 日志明确记录切集、恢复和停止的原因及关键时间值。

## 非目标

- 不修改网盘代理服务或 mpv 的网络读取实现。
- 不无限重试提前 EOF。
- 不取消正常的片尾自动跳集功能。

## 方案

`PlayerWindow` 为当前播放项维护三个观察值：

- 本集曾观察到的最大有效时长；
- 最后一个有效播放位置；
- 本集已执行的提前 EOF 恢复次数。

每次同步进度时，用正数时长更新最大有效时长，并保存有效播放位置。最大值不会因为代理临时报告较短时长而下降。若同一播放项已经记录了非零位置，mpv 在 EOF 卸载阶段报告的 `None` 或 `0` 不覆盖该位置，因为这个零值表示媒体已卸载，而不是实际播放回到开头。

片尾自动判断使用缓存的最大可信时长，而不是仅使用 mpv 当前值。收到 `playback_finished` 时，也使用缓存的最后位置和最大时长判断是否真正接近片尾：只有 `position + ending_seconds >= duration` 才按正常结束处理。

若 EOF 发生时仍明显远离片尾，则从最后有效位置重新加载当前集。第一次恢复后若同一集再次明显提前 EOF，不再循环重载，也不跳到下一集；播放器停在当前集并记录恢复失败。

## 状态生命周期

1. 开始加载新的播放项时，重置最大时长、最后位置和恢复次数。
2. 每秒同步进度时更新观察值。
3. 手动 seek、恢复加载和正常播放共用同一组观察值；seek 不会清除已知的最大时长。
4. 提前 EOF 第一次发生时，保存恢复位置，增加恢复次数，并重新加载当前项。
5. 恢复加载当前项时保留该项的最大时长和恢复次数，避免失去判定依据或形成循环。
6. 用户切集、正常自动下一集或打开新会话时重置观察状态。
7. 用户主动 seek 继续由 recent-seek 状态处理；EOF 卸载阶段的零值回退不参与最后有效位置更新。

## 结束判定

- 已知可信时长且最后位置位于片尾范围内：正常结束，允许下一集。
- 已知可信时长且最后位置远离片尾：提前 EOF。
- 未知可信时长：保持既有行为，将 EOF 当作正常结束，避免无法播放无时长媒体。
- 当前 mpv 时长小于缓存最大时长：使用缓存最大时长进行片尾判断。

## 错误处理

- 第一次提前 EOF：记录 `index`、`position`、`duration` 和恢复原因，然后从最后位置重载当前集。
- 同一集第二次提前 EOF：记录明确错误，停止当前播放，不调用 `play_next()`。
- 恢复加载同步抛错：记录恢复失败并停留在当前集。
- 正常片尾切集：记录 `reason=ending` 或 `reason=eof-near-end` 及时间值。

## 测试

采用测试驱动方式新增以下覆盖：

1. 总长 2681 秒、位置 1003 秒时收到 EOF，断言当前索引不变，并从 1003 秒重载当前集。
2. 同一集恢复后再次在远离片尾的位置 EOF，断言不重载、不切集，并记录失败。
3. mpv 当前时长从 2681 秒缩短到约 1200 秒时，进度同步不自动切集，进度条仍使用可信时长。
4. 最后位置进入配置的片尾范围时，EOF 和定时片尾判断仍正常进入下一集。
5. 未知时长媒体保持既有 EOF 行为。
6. 正常片尾后 mpv 先将位置清零再发送 EOF 时，仍按正常结束处理，不触发提前 EOF 恢复。
7. 真正提前 EOF 前 mpv 将位置清零时，仍从清零前的最后有效位置恢复。
8. 运行相关 `PlayerWindow` 与 `MpvWidget` 回归测试，确认没有新增失败。

## 验收标准

- 44:41 的视频在 16:43 提前 EOF 时不会跳到下一集。
- 第一次提前 EOF 会从最后有效位置恢复当前集。
- 重复提前 EOF 不形成无限重载，也不会错误跳集。
- 临时时长缩短不会误触发片尾自动下一集。
- EOF 卸载阶段的瞬时零位置不会覆盖最后有效播放位置。
- 正常片尾和未知时长媒体的既有行为保持不变。
